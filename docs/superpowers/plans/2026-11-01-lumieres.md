# Lumières Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Darkness at night and in the mines, light circles around the hero and dwarves blocked by rock, a dim memory of explored tiles, and six buildable light sources.

**Architecture:** All lighting rules live in a new Bevy-free module `moria_core::light` (day cycle, line of sight, per-tile brightness), so they are unit-tested in `moria-core`. The server only ships its world tick in the snapshot; darkness is a client rendering effect. The client keeps an `Explored` bitset per mountain (Bevy-free, in `crates/moria-client/src/light.rs`), saved to a local file, and `render.rs` tints sprites by the brightness of their tile.

**Tech Stack:** Rust 2024, Bevy (client), bevy_egui (HUD), postcard protocol, tokio server.

**Spec:** `docs/superpowers/specs/2026-11-01-lumieres-design.md`

## Global Constraints

- TDD is mandatory: every task writes its failing test first, runs it RED, then GREEN.
- New `Tile` and `DesignationKind` variants are appended **at the end** of their lists (postcard encoding).
- `PROTOCOL_VERSION`: 6 after Part 1 (Task 3), 7 after Part 2 (Task 7).
- 1 real hour = 1 game day = `DAY_TICKS = 36_000` ticks (100 ms tick).
- Cycle, from tick 0 (6 h, morning): full day for 15 000 ticks (6 h–16 h), dusk 3 000 ticks (16 h–18 h), night 15 000 ticks (18 h–4 h), dawn 3 000 ticks (4 h–6 h). One game hour = 1 500 ticks.
- Hero and each dwarf: light radius 4. Built sources: Chandelle 3, Torche 5, Lampe 6, Feu de bois 7, Foyer 8, Poêle 6.
- Costs: Chandelle 1 bois · Torche 1 bois · Lampe 1 pierre + 1 or · Feu de bois 3 bois · Foyer 4 pierre · Poêle 3 pierre + 2 bois.
- Light blockers are exactly `Tile::is_stone()` (rock, gold, mithril, soil, wall). A blocker receives light itself but hides what is behind it. Trees, furniture and light sources do not block.
- In full daylight outdoors, the screen must look exactly as it does today.
- Every user-visible string is in French.
- Run the checks with `cargo test --workspace` and `cargo clippy --workspace --all-targets -- -D warnings` plus `cargo fmt --check`. Share one target dir to save disk: `CARGO_TARGET_DIR=/Users/nicolaslallier/OpenCode/Moria/target`.

## Review Focus

1. **A one-tile corridor**: the hero must see both walls beside him, and the rock behind those walls must stay dark. Pinned by `corridor_lights_its_walls_not_beyond` (Task 2).
2. **A level browsed with `browse_z`** where the hero is not: no hero light on it, only dwarves, built lights and memory. Pinned by `hero_lights_only_his_own_level` (Task 4).
3. **A light near the map edge**: no panic, no index outside the mountain. Pinned by `light_at_map_corner_does_not_panic` (Task 2).
4. **A memory file that does not fit** (world reset to another size, truncated or garbage file): ignored, the game starts with no memory and does not crash. Pinned by `explored_rejects_wrong_size_bytes` (Task 4).
5. **A dwarf in a remembered but unlit area** shows no head, while a dwarf always lights its own tile. Pinned by `dwarf_is_visible_only_where_lit` (Task 5).

### Task 2: Brightness map with line of sight

**Files:**
- Modify: `crates/moria-core/src/light.rs`

**Interfaces:**
- Consumes: `daylight` (Task 1), `Mountain::get`, `Tile::is_stone`.
- Produces:
  - `pub const BODY_LIGHT: u8 = 4;` (hero and dwarves)
  - `pub const MOONLIGHT: f32 = 0.12;`
  - `pub fn blocks_light(t: Tile) -> bool` (= `t.is_stone()`)
  - `pub fn light_radius(t: Tile) -> Option<u8>`: `None` for every tile in Part 1 (Task 7 fills it).
  - `pub struct Area { pub x0: i16, pub y0: i16, pub x1: i16, pub y1: i16 }`: inclusive rectangle of one level.
  - `pub struct LightMap` with `pub fn get(&self, x: i16, y: i16) -> f32` (0.0 outside the area).
  - `pub fn light_map(m: &Mountain, z: u8, area: Area, sources: &[(i16, i16, u8)], tick: u64) -> LightMap`. `sources` are `(x, y, radius)` on level `z`; built light tiles inside the area grown by 8 are added by `light_map` itself through `light_radius`.

Rules `light_map` must follow:
- A source lights tile `t` when the Euclidean distance `d ≤ r` and the Bresenham line from the source to `t` crosses no `blocks_light` tile **strictly between** them. Brightness is 1.0 for `d ≤ r − 1` and 0.5 for `r − 1 < d ≤ r` (the fade).
- **Outdoors**: a tile whose tile above is `Sky`, or a `Sky` tile, or any tile on level 0, gets `max(daylight(tick), MOONLIGHT)`. A `blocks_light` tile with a 4-neighbour outdoor tile gets the same value.
- The result per tile is the max over every contribution. Coordinates outside the mountain are never read (out-of-range `get` returns `None`, treated as non-blocking darkness).

**Interfaces:**
- Consumes: Tasks 2–4.
- Produces:
  - `pub fn clock_label(tick: u64) -> String` in `game.rs`: `"{h} h — Jour"`, `"— Crépuscule"`, `"— Nuit"` or `"— Aube"`, by the cycle phase.
  - `pub fn dwarf_visible(light: f32) -> bool` in `light.rs`: `light >= SEEN_AT`.
  - A `Lighting(LightMap)` Bevy `Resource` in `render.rs`, recomputed by a new `compute_light` system chained **before** `sync_tiles`. The cache key is `(g.tick / 150, hero pos, current_z, dwarf positions, Session::snapshots, number of tiles changed by the last tick > 0, view radius)`. The area is the view radius around the hero. Each lit tile with `light >= SEEN_AT` is marked in `g.explored` (this needs `ResMut<Client>`).

Rendering rules:
- `sync_tiles`: multiply the existing per-tile color variation by `shown(light, seen)`. Quantize to 1/32 and add it to the `TileSprite::shown` key so only changed cells are rewritten. A tile at 0.0 is drawn black. **In full daylight outdoors the multiplier is 1.0, so today's look is unchanged.**
- `sync_marks`: a dwarf's head is `Visibility::Hidden` unless `dwarf_visible(light at its tile)`. The hero is always visible.
- `draw_relief` and the dwarf circles: skip tiles whose shown brightness is 0, and multiply the line colors by the shown brightness.
- `draw_outlines`: draw designations only on tiles that are lit or explored.
- `hud`: one more line, `clock_label(g.tick)`.
